### Fixes applied during re-QA (7)
1. **A1.2 — gradient discipline:** removed the decorative radial-gradient glow from the hero; the hero is now a flat `--bg` field.
2. **A2.1 — palette provenance:** all one-off hex values removed from components (`#0b0b0c` ×5 and `#ff9d8a` are now tokens); `--muted` set to the Standard's on-ink secondary `#B9BEC7`; `--line` set to the Standard hairline `#232529`; added `--error` and `--radius-btn` tokens.
3. **§1.3 — typography:** display face changed Archivo → **Space Grotesk** (500/600/700) as the Standard prescribes for this industry; display weights normalised to 700; step/row numbers set in tabular figures.
4. **A5.3 — motion discipline:** the uniform reveal-on-scroll system (50 elements, identical 0.6s timing — the exact A5.3 fail pattern) removed entirely: CSS, JS, the noscript override and the classes. Content is static and fully visible with JS disabled; remaining motion is functional only (hover states, table-row highlight).
5. **§1.5 — components:** primary button radius 999px pill → **4px** (`--radius-btn`); the six roadmap services rebuilt from identical cards into a **numbered editorial row list**; the 13 demo cards rebuilt into a **work-index table** (Project / Type / Status / Link), category filters re-wired to the table rows, rows stacking with labels at ≤700px.
6. **§1.5 — process:** steps restyled from card boxes to a plain hairline list. **Step count stays 5, not the Standard's 4 — recorded deviation:** MTS's real recorded process has five steps and the Blueprint step is Asad's standing rule (blueprint/sitemap approved before any code); merging steps would misstate the real process. Step texts name each step's output; **durations are not stated because none are recorded anywhere — inventing them would breach the honesty rules.**
7. **§0.1 — reflow:** the contact email link given `overflow-wrap: anywhere` so the long address cannot force horizontal scroll at 320px.

Post-fix validation: HTML tag balance clean (parser, 0 errors), exactly 1 H1, every in-page anchor resolves, all JS-referenced ids present, JS syntax OK, 13 demo rows + 6 service rows in place, 0 dead `#` links, 0 gradients, 0 one-off hex values outside `:root`.
